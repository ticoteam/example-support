# knowledge

This bot's own documentation of its domain: the standing answer to "what do we actually know about
this?" Read it first in a fresh session. Other bots may read it if they list this repository under
`reads:` in their `employee.yaml`. Assume a human and another bot will read everything here.

- One topic per file. Prefer updating a file over adding a new one.
- Plain markdown, short sections. Every file ends with a dated `## Sources` section.
- When two sources disagree, record both with their dates. Never invent; if nobody said a number,
  there is no number.
- No secrets, and no personal details beyond what the source already shows.
- `memory/learnings.md` is how to do the job; `knowledge/` is what is true about the domain.
